Guides for making and testing Minecraft mods with Modsmith {{version}}.

Guides

Getting started

Install Modsmith, create a Fabric, NeoForge or Forge mod from a template, and launch Minecraft with it.

Build and test a mod

Build with Gradle, run a test client or dedicated server, apply code changes without restarting, and debug.

Test with other mods

Add mods from Modrinth, CurseForge or JAR files, import or link a modpack, and manage versions.

Troubleshooting

Java versions, Gradle errors, trust, the Minecraft EULA, CurseForge downloads and Linux docking.

Help and feedback

Report problems or ask questions in the GitHub issue tracker. Include your Modsmith version (Settings, About) and, for build or launch problems, the task log from the Tasks panel.
