Install on Windows

  1. Download {{download:windows:name}} and run it.
  2. The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Choose More info, then Run anyway, if you trust the download from the GitHub release.
  3. Start Modsmith from the Start menu.

Modsmith uses Microsoft Edge WebView2, which Windows 11 includes. Close Modsmith before installing a newer version over it.

Install on Linux

For the AppImage, make the file executable and run it:

chmod +x {{download:appimage:name}}
./{{download:appimage:name}}

On Debian or Ubuntu, install the package with apt:

sudo apt install ./{{download:deb:name}}

Embedding the game window in Modsmith needs X11 or XWayland. In a pure Wayland session the game opens in its own window. See Linux notes for details.

What else you need

  • Java. Modsmith finds installed JDKs. When a project needs a version you do not have, it offers to download Eclipse Temurin into its own data folder. Fabric projects built with Loom 1.18 need JDK 25 for Gradle; Minecraft 1.21.1 runs on Java 21 or newer.
  • Internet access for the first build of a project (Minecraft, the loader and its Gradle plugin are downloaded once) and for Modrinth and CurseForge.
  • A CurseForge API key only if you want to search CurseForge from Modsmith. Modrinth works without one.

Updates

When it starts, Modsmith checks GitHub for a newer release and shows a notice with a download link. It never downloads or installs updates on its own. You can turn the check off in Settings, About.
