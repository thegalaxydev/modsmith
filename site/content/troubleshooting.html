Troubleshooting project setup

Solutions for the problems people most often hit when installing Modsmith, creating a project or launching Minecraft. Each section starts with what you see.

Installing and updating

Windows says "Windows protected your PC"

The installer is not code-signed yet. If you downloaded it from the GitHub releases, choose More info, then Run anyway.

The installer says "Error opening file for writing … modsmith-service.exe"

Modsmith is still running. Close the Modsmith window, then press Retry. Modsmith's background service stays running for MCP clients after the window closes; if the error remains, end modsmith-service.exe in Task Manager and press Retry again.

Java problems

"This needs Java that is not installed yet"

The project needs a Java version you do not have. Choose Yes to download Eclipse Temurin from Adoptium into Modsmith's data folder; it is a one-time download of a few hundred megabytes. To use a JDK you installed yourself, open Settings, Java and press Rescan or Add Java home.

Gradle fails on a Fabric project with a Java version error

Fabric projects use Loom 1.18, which needs JDK 25 to run Gradle even when the mod targets Java 21. Modsmith picks a suitable JDK automatically when one is installed. If the build was started outside Modsmith, set JAVA_HOME to a JDK 25 or newer. NeoForge 1.21.1 projects need JDK 21 for Gradle.

Minecraft does not start on an old version

Minecraft 1.14.4 to 1.16.5 run on Java 8, and newer versions on 17, 21 or 25. Modsmith uses the lowest installed Java that the version accepts; install the version it asks for, or pin a Java runtime for the configuration under Configs, Advanced settings.

Project setup

"This project has not been trusted yet"

Modsmith opens folders without running anything. Building or launching runs the project's Gradle scripts, so Modsmith asks first. Choose Yes when you are asked to trust a project you created or whose source you trust.

"This folder is not set up as a Modsmith project yet"

The folder has no modsmith.json. On the Overview page, under Set up this folder, choose the project type, check the Minecraft and loader versions Modsmith detected, and press Set up project. It creates modsmith.json and adds .modsmith/ to .gitignore; your build files are not changed.

"… projects can be browsed and edited, but building and launching are not available for this loader yet"

The project uses Forge, Quilt, Architectury or NeoForge with NeoGradle. Modsmith currently builds and launches Fabric (Loom) and NeoForge (ModDevGradle) projects only.

Project creation failed

The files and logs created so far stay in the project folder; the log is in .modsmith/logs. The most common causes are a missing JDK (see above) and a network error while Gradle downloads Minecraft. Press Back to review and create the project again in an empty folder, or open the folder and run Build from More actions.

A Minecraft version is not available in the New mod wizard

Versions shown as "(not available yet)" have not passed the automated build and launch checks. Fabric supports 1.14.4 to 26.3 and NeoForge 1.20.4 to 26.3; NeoForge 1.20.1, 1.20.2 and 1.20.5 are not available. Starter content beyond the empty mod is only available on 1.21.1.

Running the game

The dedicated server asks about the Minecraft EULA

A Minecraft server only starts after its EULA is accepted. Modsmith asks once per server configuration and never accepts it for you. Read the Minecraft EULA and choose Yes to accept it for that test server.

The game opens in its own window instead of inside Modsmith

Embedding is available on Windows and on Linux with X11 or XWayland. In a native Wayland session the game opens in its own window. Also check that Auto-embed is ticked on the Client tab, or press Embed here.

Apply changes says hot reload is off

Hot reload needs the configuration's debug port. Press Turn on and restart. If the port is in use by another program, Modsmith asks before using a different one.

The development bridge is not connected

The Inspector, screenshots, scenarios and benchmarks use the development bridge. Turn on Development bridge for the configuration on the Configs page and restart the game. The bridge is available for Minecraft 1.21.1.

Mods and modpacks

CurseForge search is not available

CurseForge requires each user to have an API key. Create one in the CurseForge for Studios console, then add it in Settings, Providers, CurseForge API key. You can still import a CurseForge .zip modpack from a file without a key.

A CurseForge mod needs a manual download

The mod's author does not allow downloads from other applications. Open the mod's page from its details, download the file, and press Provide downloaded file. Modsmith checks the file's hash before using it.

Still stuck?

Open an issue on GitHub with your Modsmith version (Settings, About), your operating system, the loader and Minecraft version, and the task log from the Tasks panel.
